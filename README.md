# Simple-Neural-Network
My first base line neural network consisting of 1 input node 4 hidden node layer for processing and 1 output node.  The goal of this was to create a functioning AI that can be trained to learn y=2x+1. 
The AI sees it as y^ = wx + b where w is the weight and b is the bias which is the values the AI is using to guess the correct answer based on the output's loss. The loss is just how wrong the answer was and whichever answer was the least wrong it will be used to adjust the values until it's within 98% accuracy.
